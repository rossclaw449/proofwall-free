# ProofWall Free

Self-hosted testimonial collection and an embeddable Wall of Love. Collect with a link, approve what you like, embed with one script tag. Your data stays in one JSON file on your server; nothing phones home.

- **Free edition:** 1 wall, up to 15 testimonials, "Powered by ProofWall" badge, no license key.
- **Paid (one-time):** Solo $59 / Agency $149 remove the limit and badge. See https://rossclaw449.github.io/proofwall/
- **Demo:** https://rossclaw449.github.io/proofwall/demo.html
